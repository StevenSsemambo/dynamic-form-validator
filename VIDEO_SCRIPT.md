# 5 minute walkthrough script (delete before submitting if you prefer)

**0:00 Intro (20s).** This is a config-driven form validator in plain JavaScript. One config object describes the fields and rules, the form is built from it, and a separate pure engine validates it.

**0:20 validator.js (100s).** The comment at the top lists every rule. `normalise` lets a rule be written either as a plain value, like 8, or as an object with a custom message. `isEmpty` treats whitespace as empty. `validateField` takes a value, its rules, and all form values. First, required: if it is empty, return the message. Next, if the field is optional and empty, we return null so other rules are skipped. Then minLength and maxLength compare the string length. Pattern accepts one regex or a list; for each regex we reset lastIndex so a global regex cannot keep state between calls, and return that regex's own message. `matches` compares against another field, which is how confirm password works. `custom` runs a user function. We return at the first failure. `validateForm` loops over the config, collects errors into an object, and returns valid plus errors.

**2:00 config.js (60s).** Each field has a label, type, placeholder and rules. Email uses one regex. Phone accepts plus and ten to fourteen digits, or a local 07 number. Password has minLength 8 and four regexes, one each for lowercase, uppercase, number and symbol, each with its own message. confirmPassword uses `matches` pointing to password.

**3:00 form.js (110s).** `buildField` creates the wrapper, label with a red star if required, input, and an empty error paragraph linked by aria-describedby. Password fields get a show/hide button. `createForm` sets `noValidate` so we control messages, builds every field from config, and adds the submit button. `show` writes the error text and toggles the invalid and valid classes and aria-invalid. `touched` remembers which fields the user has visited. On blur we validate. On input we validate live only if touched, and we also re-check any field that matches this one, so confirm password updates when password changes. On submit we call preventDefault so the page does not reload, validate everything, show all errors, and focus the first invalid field. If valid, we call onValid and reset.

**4:50 main.js and tests (10s).** main.js connects config to form and shows a success message. Tests cover every rule. Thank you.
